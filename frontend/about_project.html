BanglarBhumi Pro

A high-performance real-time land record and revenue intelligence platform engineered for West Bengal citizens and property researchers.

Launch Search App Live Production Site View Source on GitHub
⚡

Dual Presentation Views

Switch seamlessly between modern data analytics and certified administrative outputs:

  • Modern Ledger: Fast searchable grid with share calculation and filtering.
  • Official Portal Format: Exact 1:1 replica of the state format with responsive horizontal swipe for mobile.
  • Cadastral Plot Map: Scaled SVG parcel visualizer with interactive zoom.
🛡️

Privacy & Security Architecture

Designed around local-first privacy with no cloud credential storage:

  • Zero Remote Storage: Citizen login passwords and OTPs are never stored in any database.
  • Local Sessions Only: Session tokens and browser cache stay strictly on your local machine.
  • No Telemetry: Zero third-party analytics, tracking scripts, or profiling trackers.
🚀

Core Technologies

Built with lightweight, high-performance web standards:

  • Backend: Node.js, Fastify 3.x, Asynchronous SSL Connection Pool.
  • Engine: Puppeteer Stealth with automated Chrome DevTools Protocol.
  • Frontend: Vanilla HTML5, CSS3 Grid/Flexbox, ES6+ JavaScript.
  • Container: Docker Debian Chromium with FreeFonts Bengali.
