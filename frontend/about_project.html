Background & Motivation

The state portal for land records in West Bengal (Banglarbhumi) was architected over a decade ago. While its underlying database contains comprehensive revenue records across all 23 districts, its user interface presents major usability hurdles for modern devices:

1. Severe Mobile Clipping: The official site outputs tables with rigid widths (680px minimum) enclosed in fixed wrappers. On modern smartphones, column headers such as Rayat Share, Acreage, and Remarks become completely unreachable without browser horizontal pan.

2. Truncated Owner Names: Official HTML table structures inject non-standard whitespace constraints that clip long multi-line names of joint property holders (সহ অংশীদার).

3. Absence of Search Filtering: A large Khatian with dozens of co-sharers requires tedious manual visual scanning. BanglarBhumi Pro introduces real-time text filtering and instant acreage calculation.

Technical Architecture

The platform follows a modular, low-latency, and dependency-conscious software architecture:

Component Technology Design Rationale
Backend Routing Fastify 3.x on Node.js Low-overhead asynchronous HTTP dispatch with custom SSL connection pooling for legacy TLS state endpoints.
Automation Service Puppeteer Stealth (CDP) Handles CAPTCHA retrieval and session bridging without user-agent detection flags.
Frontend Interface Vanilla ES6+, CSS Grid, Flexbox Zero runtime bundle overhead; responsive layout engine supporting Hind Siliguri and Plus Jakarta Sans.
Container Runtime Docker (Debian Bookworm) Multi-stage container with bundled Chromium headless binary and Bengali font packs.

Security, Privacy & Data Stewardship

Local-First Guarantee: BanglarBhumi Pro does not transmit citizen credentials, phone numbers, or queried land records to any third-party cloud service, tracking server, or database.

• Transient Authentication: When signing in via the citizen bridge, credentials and OTP verification tokens are passed over secure HTTPS directly to banglarbhumi.gov.in to obtain an official session cookie.

• Local Session Caching: Session cookies are cached solely on the host computer at backend/data/citizen_session.json and .banglarbhumi-browser/. These paths are ignored in .gitignore and .dockerignore.

• Responsible Fair-Use: This tool is intended for personal and research productivity. Users must adhere to fair usage policies and refrain from running high-concurrency automated scrapers against government servers.
